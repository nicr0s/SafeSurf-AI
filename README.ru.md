**SafeSurf AI** объединяет расширение для Chromium-браузеров и локальный Flask API. Система извлекает текстовые и структурные признаки URL, а ансамбль **Random Forest, XGBoost и Logistic Regression** классифицирует ссылку как `phishing` или `legitimate`.

Проект создан в рамках дипломной работы *Detection of Phishing Attacks Using Machine Learning*. В репозитории находятся приложение для предсказаний, сохранённые модели и интерфейс расширения.

> **Исследовательский прототип.** У текущей модели есть ложные срабатывания. Уведомление появляется после перехода и не блокирует страницу. Подробности — в разделе [ограничений](#текущие-ограничения).

## Основные компоненты

| Компонент | Реализация |
| --- | --- |
| Браузерное расширение | JavaScript, HTML, CSS · Manifest V3 |
| Сервис предсказаний | Python · Flask · `localhost:5001` |
| Представление URL | 500 TF-IDF компонентов + 21 числовой признак |
| Классификатор | Усреднение вероятностей RF + XGBoost + LR |
| Локальное хранилище | История, обнаруженные ссылки, доверенные домены |
| Исследование | В дипломе описан датасет из 95 910 URL |

## Интерфейс расширения

<p align="center">
  <img src="docs/assets/popup.png" alt="Интерфейс SafeSurf AI: экспорт CSV, управление базой, доверенные сайты и история" width="290">
</p>

<p align="center"><sub>Текущий интерфейс отрисован из исходников с пустым локальным хранилищем.<br>Это превью интерфейса, а не полный тест установленного расширения.</sub></p>

- **Автоматические проверки URL** при событиях вкладок и навигации, включая смену адреса в SPA.
- **Уведомления на странице** с классификацией и отдельными индикаторами URL.
- **История последних пяти проверок API** с оценкой модели и временем.
- **Доверенные домены**, включая поддомены, для которых модель не вызывается.
- **Экспорт CSV** с локально сохранёнными URL, классифицированными как phishing.
- **Компактный режим** кнопок без текстовых подписей.

Предсказания выполняются на вашем компьютере. Классификатор анализирует строку URL, не загружает содержимое проверяемой страницы и не отправляет ссылки облачному сервису классификации.

## Как это работает

<p align="center">
  <img src="docs/assets/architecture.svg" alt="URL в браузере → локальный Flask API → 521 признак → ансамбль моделей → уведомление" width="100%">
</p>

1. Расширение получает URL при событии вкладки или навигации.
2. Доверенный домен получает метку `legitimate` без обращения к модели.
3. Остальные URL отправляются на `POST http://localhost:5001/predict`.
4. Python преобразует токены URL в TF-IDF и вычисляет 21 числовой признак: длину, структуру hostname, индикаторы слов, кодировки и энтропию символов.
5. Сохранённый scaler преобразует числовые признаки. Ансамбль обрабатывает объединённый вектор из **521 признака**.
6. API возвращает класс, оценку phishing и исходные признаки. Расширение показывает уведомление и сохраняет локальные результаты.

«Причины» в уведомлении определяются простыми правилами по значениям признаков. Это не объяснение голосования модели и не SHAP-анализ. Подробности — в [описании модели](docs/MODEL.md).

## Быстрый старт

### 1. Клонировать проект

```bash
git clone https://github.com/nicr0s/SafeSurf-AI.git
cd SafeSurf-AI
```

### 2. Запустить API

Можно использовать Python или Docker. Выполняйте команды из корня репозитория: приложение загружает модель по относительному пути.

<details open>
<summary><strong>Окружение Python</strong></summary>

Создайте окружение с Python 3.11 или новее:

```bash
python -m venv .venv
```

Активируйте его в Windows PowerShell:

```powershell
./.venv/Scripts/Activate.ps1
```

Или в macOS / Linux:

```bash
source .venv/bin/activate
```

Установите зависимости и запустите сервер:

```bash
python -m pip install flask flask-cors joblib tldextract scipy "scikit-learn==1.6.1" "xgboost==2.1.4"
python app.py
```

Модель сохранена с scikit-learn `1.6.1` и XGBoost `2.1.4`. Предсказания проверены локально с этими версиями на Python 3.13; остальные сочетания Python и платформ здесь не проверялись.

</details>

<details>
<summary><strong>Docker</strong></summary>

Запустите Docker Desktop или Docker Engine, затем выполните:

```bash
docker build -t safesurf-ai .
docker run --rm -p 127.0.0.1:5001:5001 safesurf-ai
```

Текущий Dockerfile использует Python 3.11. В рамках этого разбора Docker-запуск не проверялся; кавычки в команде установки зависимостей и фиксация версий включены в [план развития](docs/ROADMAP.md).

</details>

Оставьте API запущенным на время работы расширения. Открытие `/` в браузере возвращает `404`; реализован endpoint `POST /predict`.

### 3. Установить расширение

1. Откройте `chrome://extensions` в Chrome, `edge://extensions` в Edge или `brave://extensions` в Brave.
2. Включите **режим разработчика**.
3. Нажмите **«Загрузить распакованное»** и выберите папку `my-extension`.
4. Закрепите **SafeSurf AI** на панели для доступа к истории, доверенным сайтам и экспорту.
5. Откройте страницу с HTTP или HTTPS, чтобы запустить проверку.

Расширение предназначено для Chromium-браузеров. Полная установка и проверка интеграции в браузере в рамках этого разбора не проводилась.

### 4. Проверить API

В macOS / Linux или другой оболочке со стандартными кавычками curl:

```bash
curl http://localhost:5001/predict -H "Content-Type: application/json" -d '{"url":"https://du.astanait.edu.kz/"}'
```

В Windows PowerShell:

```powershell
$body = @{ url = "https://du.astanait.edu.kz/" } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:5001/predict" -Method Post -ContentType "application/json" -Body $body
```

Ниже — часть фактически полученного локального ответа. Полный ответ содержит все 21 исходных признака:

```json
{
  "prediction": "legitimate",
  "probability": 0.429,
  "features": {
    "url_len": 27,
    "domain_len": 3,
    "entropy": 3.708
  }
}
```

`probability` — оценка ансамбля для класса **phishing**, даже если результат `legitimate`. Эта оценка не является проверенной гарантией безопасности.

## Исследование и результаты

В дипломе описан датасет из **95 910 URL**: **55 914 phishing** и **39 996 legitimate**, а также разделение train/test 80/20. Среди указанных источников — PhishTank, OpenPhish, Spamhaus DBL, URLhaus и рейтинги легитимных доменов.

Работа сравнивает Random Forest, XGBoost и Logistic Regression, рассматривает распределения признаков, кривые обучения и интеграцию с браузером. В разных разделах приводятся значения accuracy около **95–97%** для разных моделей или экспериментов.

**Эти метрики пока не воспроизведены для сохранённого ансамбля.** Датасет, скрипты сбора данных, notebooks обучения и полные результаты оценки в репозиторий не включены. Сейчас проект позволяет изучать приложение и запускать предсказания; для воспроизведения всего исследования нужны исходные материалы обучения.

Проверенные свойства артефактов и отдельные примеры предсказаний собраны в [описании модели](docs/MODEL.md). Проверка нескольких URL не является измерением accuracy.

## Текущие ограничения

- **Ложные срабатывания:** локальная проверка пометила `https://google.com` как phishing (`0.576`), а URL исходного проекта `https://github.com/baidar-10/Diploma` — как phishing (`0.631`).
- **Согласованность признаков:** разбор доменов и другие формулы нужно сверить с подготовкой обучающих данных.
- **События браузера:** повторные запросы и отправка ответа в текущую активную вкладку могут приводить к дублированию или неверному размещению уведомлений.
- **Ошибки API:** некорректный ввод обрабатывается непоследовательно; ошибки сервера логируются, но не отображаются в popup.
- **Область анализа:** система анализирует URL, не проверяет HTML, WHOIS, сертификаты и актуальные threat feeds, а также не блокирует переход.

В [плане развития](docs/ROADMAP.md) отдельно описаны валидация модели, надёжность расширения и упаковка проекта.
