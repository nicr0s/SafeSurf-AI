# SafeSurf AI — Детектор фишинговых ссылок

Браузерное расширение, которое в реальном времени проверяет каждый открытый URL через ML-модель и определяет — фишинг это или нормальный сайт.

## Как это работает

```
Ты открываешь сайт
       ↓
Расширение (my-extension) перехватывает URL
       ↓
Отправляет его на локальный сервер (Flask API, порт 5001)
       ↓
Сервер прогоняет URL через обученную ML-модель
       ↓
Возвращает результат: phishing / legitimate
       ↓
Расширение показывает предупреждение или ок
```

## Структура проекта

```
Diploma/
├── app.py                        # Flask API-сервер — принимает URL, возвращает предсказание
├── phishing_model_bundle.pkl     # Обученная ML-модель (RandomForest + XGBoost + TF-IDF)
├── Dockerfile                    # Инструкция для сборки Docker-контейнера
└── my-extension/                 # Браузерное расширение (Chrome)
    ├── manifest.json             # Конфиг расширения
    ├── background.js             # Фоновый скрипт — следит за вкладками, отправляет URL на сервер
    ├── content.js                # Встраивается в страницу — показывает предупреждение на сайте
    ├── popup.html/js/css         # Интерфейс попапа расширения
    └── *.svg                     # Иконки
```

## Шаг 1 — Запустить бэкенд через Docker

### Требования
- Установленный [Docker Desktop](https://www.docker.com/products/docker-desktop/) (должен быть запущен)

### Команды

```bash
# Перейти в папку проекта
cd /путь/до/Diploma

# Собрать образ (первый раз ~2-3 минуты)
docker build -t diploma-api .

# Запустить контейнер
docker run -p 5001:5001 diploma-api
```

После этого сервер будет доступен на `http://localhost:5001`.  
Терминал с запущенным контейнером **не закрывать** — расширение обращается к нему в реальном времени.

### Проверить что сервер работает

```bash
curl -X POST http://localhost:5001/predict \
  -H "Content-Type: application/json" \
  -d '{"url": "https://google.com"}'
```

Ответ должен быть примерно такой:
```json
{
  "prediction": "legitimate",
  "probability": 0.04,
  "features": { ... }
}
```

## Шаг 2 — Установить расширение в браузер

> Работает в Chrome, Brave, Edge и любом Chromium-браузере.

1. Открыть в браузере: `chrome://extensions`
2. Включить **«Режим разработчика»** (переключатель в правом верхнем углу)
3. Нажать **«Загрузить распакованное»**
4. Выбрать папку `my-extension` внутри проекта
5. Расширение **SafeSurf AI** появится в списке

После установки иконка расширения появится в панели браузера. Теперь при открытии любого сайта расширение автоматически проверяет URL.

---

## Важно

- Docker-контейнер должен быть запущен **до** того как использовать расширение
- Если контейнер остановлен — расширение молча не будет проверять ссылки (ошибка в консоли)
- Расширение хранит историю последних 5 проверенных сайтов
- Сайты можно вручную добавить в доверенные через кнопку **"Trust this site"** в попапе
